# all-spikes

One self-contained directory per spike: `all-spikes/<idea-slug>/`. Everything about
a spike — log, scripts, data, notes, plots, draft, PDF — lives inside its own dir
and nothing leaks outside it.

The running log in each spike dir should track, per the ladder: the claim, the rung
that killed or passed each candidate, the written-down kill-criterion, results, and
surprises — enough that the work can be resumed cold.

Mark every deliberate shortcut with a `rigor:` comment (ceiling + upgrade trigger)
so `/rigor-debt` can harvest it before you write.
